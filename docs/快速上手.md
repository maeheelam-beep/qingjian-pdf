# 青笺 PDF · 快速上手

## 1. 打开应用

运行 `Qingjian-PDF-1.1.0-portable.exe`。窗口没有系统边框，右上角是最小化、最大化与关闭。

左侧是工作台、全部工具和最近处理。底部固定入口可以调整颜色、字号与动效。

## 2. 选择文件

每个工具都支持：

- 点击「选择文件」从系统文件对话框打开
- 将文件拖入虚线区域
- 在工作台一次放入多个文件，再选择推荐工具

文件只会在内存中被读取。窗口关闭后，临时内容不会留在这台电脑上。

## 3. 处理与保存

右侧摘要栏会显示当前文件数量、处理方式和「本机处理」状态。点击主按钮开始处理，顶部进度卡会显示阶段。

处理完成后，先点击「保存文件」选择输出位置；保存成功后可以直接打开所在文件夹。

## 4. 几个常用流程

### 合并与整理

1. 「合并 PDF」添加多个文件，用文件右侧箭头调整顺序，点击「开始合并」。
2. 「整理页面」在页面卡片上拖动排序，卡片底部可以旋转或删除单页。

### 从 PDF 到 Office

- 「PDF 转 Word」建议先用「可编辑文字」；复杂版式选「保留版式」。
- 「PDF 转 Excel」会按文字坐标尽量拆分列，扫描件先用 OCR。
- 「PDF 转 PPT」每页会作为高清图片放入幻灯片，适合展示。

### 签署与脱敏

- 「签署 PDF」支持手写、输入和上传签名，可拖动签名位置。
- 「涂黑脱敏」是永久遮罩：导出文件会栅格化，被遮住的文字无法恢复。请保留原文件。

### 加密与解锁

- 「加密保护」支持 AES-256、打开密码、所有者密码和打印 / 复制 / 编辑权限。
- 「解除密码」需要输入已知密码。输出会重建为无加密 PDF，页面内容保留，表单与书签不保留。

### OCR

选择扫描件，语言默认「中文 + 英文」，首次识别需要加载本地模型。输出可以是可搜索 PDF 或纯文本。

## 5. 偏好设置

- 显示模式：浅色 / 深色 / 跟随系统
  - 「跟随系统」会随 Windows 的深色模式自动切换，无需重启。
- 浅色色温：暖白 / 宣纸 / 雾青
- 强调色：苔绿 / 松绿 / 鼠尾草（深色模式下会自动提亮）
- 字号与动效
- 是否记录最近打开的文件位置

所有偏好只保存在本机。若关闭「记住最近打开的文件位置」，之后不会再新增记录。

## 6. 遇到问题

- 文件无法打开：先尝试「修复 PDF」。严重截断的文件可能只能恢复部分页面。
- 转换后版式差异：PDF 与 Office 之间没有完美的本地排版引擎，复杂表格 / 浮动元素可能需要手动调整。
- 加密文件：需要密码；忘记密码无法恢复。
- 扫描件 OCR 不准：提高拍摄亮度、保持纸张平整，或先裁切掉无关区域。
